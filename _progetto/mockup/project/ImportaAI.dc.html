Da un'altra app, con un'AI

folio non legge i formati delle altre app. Un assistente AI sì: gli dai il file e queste istruzioni, lui ti restituisce uno .zip pronto da importare.

1
Esporta le note dall'altra app. Da Evernote su computer: File > Esporta, formato .enex.
2
Dai all'assistente il file e queste istruzioni.
Come vuoi ritrovarle?
3
Importa qui lo .zip che ti restituisce.
  • Così le note passano dall'assistente che scegli tu. folio non le manda a nessuno.
  • Se il file è troppo grande per l'assistente, esporta un taccuino alla volta.
  • Serve un assistente che sappia leggere file e crearne.
